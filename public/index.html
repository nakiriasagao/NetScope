图例说明

节点颜色（表达角色）
  • 绿色 · 起点 / 本机带呼吸光晕；本机与网关同址时会合并为「本机 / 接入点」
  • 蓝色 · 中间节点（正常）路由途中的路由器 / 骨干设备，延迟与丢包都正常
  • 粉色 · 目标探测的终点，带一圈同心环标记
  • 灰色 · 完全无响应该跳三次探测都没有回应（显示为 * * *）
节点颜色（中间节点的异常提示）
  • 黄色 · 轻微异常丢包 ≥ 20%
  • 红色 · 明显异常丢包 ≥ 50%，或超时跳，或平均延迟 > 180 ms

「超时跳」指该跳本身没有回包，但后面的跳能回应——说明它只是不响应探测， 链路本身是通的。红色更多时候表示这一段慢或丢包，而不是断网。

连线
  • 绿 / 黄 / 红 · 按延迟着色可在左侧「连线着色」切换为按跳数渐变、按丢包率或单色
  • 流动光点 · 数据包动画延迟越高流动越慢，直观表达「慢在哪一段」
  • 第 6 跳 · 12 ms线上文字 · 跳数与延迟内置地图与高德地图都会显示
  • 虚线 / 空白 · 跳过的未定位跳点该跳没有地理位置，不参与连线（地图上表现为一段空白）
局域网拓扑（点「扫描局域网设备」后）
  • 黄色 · 网关 / 路由器星型拓扑的中心
  • 绿色 · 本机
  • 粉色 · 互联网标注公网出口 IP
  • 蓝色系 · 同网段设备按类型区分：电脑、手机、打印机、NAS、摄像头、电视、IoT 等

地图设置 · 高德地图 (AMap)

高德 JS API 需要 Key 才能加载底图。请到 高德控制台 申请（需先完成个人开发者实名认证）：

  1. 「应用管理 → 我的应用 → 创建新应用」；
  2. 添加 Key 两次：一次选「Web端(JS API)」用于加载底图，一次选「Web服务」用于 IP 定位等接口；
  3. 在 Key 的「设置」里查看安全密钥(jscode) —— 2021-12-02 之后申请的 Key 必须填写；
  4. 域名白名单建议设为「不限制」，否则用 127.0.0.1 访问可能报 INVALID_USER_DOMAIN。

密钥保存在本机：data/amap-config.json（已加入 .gitignore，不会上传）。 安全密钥由服务端代理使用，不会出现在页面源码里。
